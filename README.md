# MeshCentral Реаниматор ТТ (ИИ)

Автономный ИИ-агент экстренной диагностики и восстановления аптечных касс, серверов и рабочих станций сети аптек прямо из веб-интерфейса MeshCentral.

## Возможности
1. **Кнопка в статусе компьютера:**
   - При открытии любого компьютера в MeshCentral на вкладке статуса («General» / `#p10info`) появляется кнопка **«🚑 Реаниматор ТТ (ИИ)»**.
2. **Без передачи файлов на аптеку (Zero File Transfer):**
   - На удаленный компьютер НЕ загружаются бинарные файлы, сторонние агенты или громоздкие утилиты.
   - Все диагностические и лечебные команды выполняются встроенным механизмом PowerShell через нативный агентский канал MeshCentral.
3. **Глубокая база знаний аптечной инфраструктуры:**
   - 1С:Предприятие 8.3 (кэши, блокировки `1Cv8.1CL`/`1Cv8.cfl`, защита лицензий `*.lic`, `chdbfl.exe`).
   - ККТ АТОЛ (служба `EoUService`, `EthOverUsb.exe`, `settings.xml`, COM-порты).
   - Сканеры штрих-кода (Honeywell, Mertech, Mindeo).
   - Эквайринговые терминалы (Сбербанк UPOS, Kozen).
   - Диспетчер очереди печати Windows (`Spooler`).
   - Зависания Проводника Windows (`desktop.ini`, ShellEx).
4. **Быстрые сценарии в 1 клик:**
   - 🩺 Экспресс-диагностика ТТ
   - 💊 Авария 1С: кэш и блокировки
   - 🧾 ККТ АТОЛ / ОФД (EoUService)
   - 🖨️ Сброс диспетчера печати (Spooler)
   - 🧹 Очистка диска C: и мусора
   - 🌐 Диагностика сети и связи ТТ
5. **Интерактивный диалог и безопасность:**
   - Возможность описать любую проблему свободным текстом на русском языке.
   - ИИ-агент самостоятельно вызывает диагностические команды.
   - Для любых модифицирующих команд запрашивается подтверждение оператора с подробным пояснением, что именно будет изменено.
